Reference: independent pure-double reimplementation of each converter (linear, zero-order-hold, sinc polyphase), parsing the project's own coefficient tables. Library outputs are rounded to binary32 at the API boundary, so the reference is rounded the same way before comparison. ZOH and LINEAR produce bit-identical output in both builds. Sinc tiers differ only because the default build stores coefficients and the delay line in binary32; the double build keeps coefficients, delay line and accumulation all in binary64 while sharing the identical control logic and quality tiers.
